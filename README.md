# Consultancy Web | Landing Page + Backend

### Description

Ad Hoc is a data science and software company. This landing page is the gateway to
start working with them.

This page allows custumers get informed about different offered products, projects, portafolios,
and relevant information.

It is also possible to customers log in their accounts to review orders, project statuses,
payment information, etc.

### Stack

- Django 6.1.2
- HTML5
- CSS
